# Ipiran — آیپی ایران

دو حالت دارد؛ بسته به اینکه چه می‌خواهی:

| حالت | مسیر | برای چه |
|------|------|---------|
| **پنل تک‌سرور** (`scripts/install.sh`) | گوشی → سرور ایران → مقصد | ساده، سریع، آی‌پی ایران برای برنامه‌های ایرانی |
| **ربات واسطه** (`scripts/install-bot.sh`) | گوشی → سرور خارجی → سرور ایران → مقصد | آی‌پی تو از سرور ایران و از مقصد مخفی، چند سرور ایران با failover، مدیریت از تلگرام |

راهنمای کامل ربات: [`bot/README.md`](bot/README.md).

> **کدام را انتخاب کنم؟** اگر فقط آی‌پی ایرانِ سریع می‌خواهی، پنل تک‌سرور.
> اگر می‌خواهی آی‌پی واقعی‌ات حتی از خود سرور ایران هم مخفی بماند و چند سرور
> ایران با جابه‌جایی خودکار داشته باشی، ربات واسطه. ربات کندتر است چون ترافیک
> دو بار از مرز رد می‌شود.

---

## پنل تک‌سرور

پنلی سبک برای مدیریت یک سرور **VLESS + REALITY** داخل ایران. برای استفاده‌ی
شخصی: وصل‌شدن با آیپی ایران به برنامه‌های ایرانی، با یک پنل تمیز فارسی برای
دیدن مصرف و مدیریت کانفیگ‌ها.

> روی یک سرور اوبونتو اجرا می‌شود. کاربر و سرور هر دو داخل ایران هستند.

---

## این پنل چه می‌کند

- **VLESS + REALITY + Vision** روی پورت ۴۴۳؛ سریع و بدون نیاز به دامنه.
- **Sniffing روشن:** نام مقصد روی سرور خوانده و با DNS ایران حل می‌شود، پس
  درخواست‌های DNS دستگاهت به اپراتور درز نمی‌کند و سایت‌های روی CDN درست باز
  می‌شوند.
- **قطع/وصل زنده‌ی کانفیگ:** افزودن و حذف کاربر بدون ری‌استارت و بدون قطع‌شدن
  بقیه، از طریق gRPC API خود Xray.
- **سهمیه‌ی حجمی و تاریخ انقضا** که خودکار اعمال می‌شوند.
- **پنل فارسی راست‌به‌چپ** با سرعت لحظه‌ای، مصرف هر کاربر، تعداد دستگاه‌های
  آنلاین، و نمودار مصرف ۱۴ روز.
- **QR و لینک اشتراک** برای v2rayNG و Hiddify.

## دیدن اینکه واقعاً کار می‌کند

### مسیر ترافیک

پنل زنجیره‌ی واقعی را از کانفیگ در حال اجرا می‌خواند و مرحله‌به‌مرحله نشان
می‌دهد: استتار REALITY، اسنیفینگ، حل نام با DNS سرور، و خروج به اینترنت.

بالای همین کارت یک قضاوت هست که خودش مدرک است. پنل روی همان سروری اجرا می‌شود
که تونل را تمام می‌کند، پس اگر ترافیکت از تونل رد شود، آدرسی که پنل از تو
می‌بیند **خود سرور** است نه آی‌پی اینترنتت. اگر فیلترشکن روشن باشد پیام سبز
می‌بینی، و اگر خاموش باشد پنل آی‌پی واقعی‌ات را نشانت می‌دهد. مقایسه‌ی همین دو
حالت ثابت می‌کند آی‌پی عوض شده.

### مونیتور زنده

به‌طور عادی سرور هیچ لاگی نگه نمی‌دارد. با یک دکمه ۱۰ دقیقه پنجره‌ی نمایش باز
می‌شود و هر سطر نشان می‌دهد دستگاهت چه آدرسی خواسته و سرور چه نامی از دل
ترافیک بیرون کشیده:

```
19:26:25   اسنیف شد   rubika.ir:443     درخواست شد: 149.6.x.x:443
19:26:38   آی‌پی خام   203.0.113.9:443
```

سطر اول یعنی نام روی سرور شناسایی شده، پس گوشیت لازم نبوده از اپراتور آدرس
بپرسد. همین تفاوت، کارکرد اسنیفینگ را ثابت می‌کند.

این پنجره عمداً محدود است:

- **لاگ دسترسی هیچ‌وقت روشن نمی‌شود.** آن لاگ است که آی‌پی کاربرها را ثبت
  می‌کند. مونیتور فقط لاگ تشخیصی Xray را می‌خواند، پس **آی‌پی هیچ کاربری
  هیچ‌جا نوشته نمی‌شود.**
- فایل زیر `/run` است، یعنی رم، نه دیسک.
- خودش منقضی می‌شود، فایل پاک می‌شود، و اگر از حد حجم بگذرد خودش خاموش می‌شود.
- روشن و خاموش کردنش Xray را ری‌استارت می‌کند، پس اتصال‌ها یک لحظه قطع می‌شوند.

## پنهان‌کاری و امنیت

- کل پنل زیر یک **مسیر مخفی تصادفی** است (`/<secret>/…`). اسکن ساده‌ی آیپی و
  پورت چیزی پیدا نمی‌کند. همین مسیر، کلید ورود است؛ لینک را نشونک کن. اگر فکر
  کردی لو رفته، از خود پنل عوضش کن یا `ipiranctl rotate-secret` را بزن.
- **محدودیت نرخ درخواست** روی هر آی‌پی، تا اسکن کردن برای پیدا کردن آن مسیر
  عملی نباشد.
- پیش‌فرض، پنل فقط روی **localhost** گوش می‌دهد و از راه تونل SSH باز می‌شود.
- **لاگ دسترسی خاموش است.** فقط حجم مصرف ذخیره می‌شود. آیپی کاربران هیچ‌جا
  روی دیسک نوشته نمی‌شود؛ تعداد دستگاه آنلاین زنده از Xray خوانده و فقط شمرده
  می‌شود.
- Xray با سرویس محدودشده اجرا می‌شود؛ پنل فقط اجازه‌ی یک دستور دارد: ری‌استارت
  Xray.
- فایروال همه‌چیز را می‌بندد جز SSH و پورت کلاینت.

> **اگر پنل را روی آی‌پی سرور باز می‌کنی، `--https` را هم بزن.** بدون آن، مسیر
> مخفی که تنها کلید پنل است به‌صورت متن ساده در شبکه‌ی اپراتور رد و بدل می‌شود.
> با `--https` یک گواهی self-signed ساخته می‌شود؛ مرورگر یک‌بار هشدار می‌دهد و
> نصب‌کننده اثر انگشت گواهی را چاپ می‌کند تا مقایسه کنی.

### چه چیزی را پنهان نمی‌کند

سرور داخل ایران است و خروجی هم ایران. این یعنی:

- سایت‌های فیلترشده باز **نمی‌شوند**؛ این ابزار برای دور زدن فیلترینگ نیست.
- برنامه‌های ایرانی با شماره موبایل تو را می‌شناسند و دیتاسنتر آیپی موبایلت را
  که به سرور وصل شده می‌بیند. این طرح آیپی واقعی‌ات را از خود برنامه پنهان
  می‌کند و از اپراتور پنهان می‌کند چه برنامه‌هایی باز کرده‌ای، ولی تو را از
  دولت پنهان نمی‌کند. برای حرف‌های حساس مناسب نیست.

## نصب

روی سرور اوبونتو:

```bash
git clone https://github.com/shootingv818/Ipiran.git
cd Ipiran
sudo ./scripts/install.sh --host <آیپی-عمومی-سرور>
```

نصب‌کننده Xray را (با بررسی checksum) نصب می‌کند، SNI مناسب را تست و انتخاب
می‌کند، کانفیگ و کلیدها را می‌سازد، پنل را به‌عنوان سرویس بالا می‌آورد و فایروال
را می‌بندد. در پایان آدرس پنل را چاپ می‌کند.

### گزینه‌ها

| گزینه | کار |
|------|-----|
| `--host X` | آدرسی که کلاینت‌ها می‌گیرند (معمولاً آیپی سرور). لازم. |
| `--port N` | پورت کلاینت (پیش‌فرض ۴۴۳). |
| `--sni HOST` | دامنه‌ی استتار REALITY؛ قبل از استفاده تست می‌شود. |
| `--panel-open CIDR` | پنل را برای این آیپی/رنج باز کن (مثلاً `1.2.3.4/32`). بدون آن، پنل فقط روی localhost. |
| `--panel-port N` | پورت پنل (پیش‌فرض ۸۷۷۷). |
| `--https` | پنل روی TLS با گواهی self-signed، تا مسیر مخفی در شبکه دیده نشود. |

### باز کردن پنل از راه تونل (حالت امن پیش‌فرض)

```bash
ssh -L 8777:127.0.0.1:8777 root@<آیپی-سرور>
# سپس در مرورگر: http://127.0.0.1:8777/<secret>/
```

## مدیریت از خط فرمان

```bash
ipiranctl add-client "گوشی علی" --quota-gb 20 --expire-days 30
ipiranctl show
ipiranctl set reality_sni www.aparat.com
ipiranctl render           # بازسازی و اعتبارسنجی کانفیگ Xray
ipiranctl url              # آدرس فعلی پنل
ipiranctl rotate-secret    # عوض کردن مسیر مخفی
```

تغییر SNI یا پورت نیاز به ری‌استارت دارد (دکمه‌ی «اعمال و ری‌استارت» در پنل یا
`systemctl restart xray`). افزودن و حذف کاربر زنده اعمال می‌شود.

## ساختار

```
panel/
  app/
    server.py    سرور HTTP (فقط کتابخانه‌ی استاندارد پایتون)
    service.py   منطق: کاربر، مصرف، محدودیت‌ها، سرعت، مسیر ترافیک
    xray.py      تولید کانفیگ، مدیریت زنده‌ی کاربر، آمار
    monitor.py   مونیتور زنده‌ی موقت روی رم
    db.py        ذخیره‌سازی SQLite
    links.py     ساخت لینک اشتراک VLESS
    cli.py       ابزار خط فرمان ipiranctl
  web/           رابط کاربری (HTML/CSS/JS، فونت و کتابخانه‌ی QR محلی)
scripts/
  install.sh     نصب‌کننده‌ی اوبونتو
```

بدون هیچ وابستگی از PyPI؛ فقط `python3` و باینری `xray` لازم است.
