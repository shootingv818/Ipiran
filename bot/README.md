# IP SAZ — ربات تلگرام واسطه و آیپی‌ساز

ربات تلگرامی که روی **سرور خارجی** اجرا می‌شود و سه نقش دارد:

1. **واسطه:** کلاینت‌ها به سرور خارجی وصل می‌شوند و ترافیکشان از آن به یکی از
   سرورهای ایران تونل می‌شود. مقصد آی‌پی **ایران** می‌بیند.
2. **مخفی‌کننده:** سرورهای ایران فقط آی‌پی سرور خارجی را می‌بینند، نه آی‌پی
   واقعی کاربر.
3. **آیپی‌ساز:** ساخت و مدیریت کاربر، سهمیه، انقضا، لینک و وضعیت — همه از توی
   چت تلگرام.

```
کلاینت ──► سرور خارجی (این ربات) ──┬─► ایران-۱ 🟢 ──► مقصد
                                    ├─► ایران-۲ 🟢
            منوی تلگرام             └─► ایران-۳ 🔴 (خودکار رد می‌شود)
```

## چرا روی سرور خارجی؟

سرور ایران به تلگرام دسترسی ندارد (تست شد: unreachable)، پس ربات آنجا کار
نمی‌کند. سرور خارجی هم به تلگرام می‌رسد و هم همان نقطه‌ای است که باید واسطه و
مخفی‌کننده باشد. ربات با long-polling کار می‌کند، پس **هیچ پورت بازی لازم
ندارد** — همان مشکلی که پنل وب روی سرور ایران داشت، اینجا اصلاً پیش نمی‌آید.

## چند سرور ایران و failover

چند سرور ایران را به استخر اضافه می‌کنی (با paste کردن لینک vless هرکدام).
سرور خارجی با balancer و probe زنده‌ی Xray، سالم‌ترین را انتخاب می‌کند و اگر
یکی مسدود یا قطع شد، **خودکار** می‌رود روی بعدی. کلاینت‌ها هیچ‌کاری نمی‌کنند و
کانفیگشان عوض نمی‌شود، چون فقط به سرور خارجی وصل‌اند.

> اگر همه‌ی سرورهای ایران قطع شوند، اتصال **بسته می‌شود** و از آی‌پی سرور خارجی
> بیرون نمی‌رود. این عمدی است تا آی‌پی خارجی به مقصد لو نرود.

## نصب (روی سرور خارجی)

۱. از [@BotFather](https://t.me/BotFather) یک ربات بساز و توکنش را بگیر.
۲. آی‌دی عددی خودت را از [@userinfobot](https://t.me/userinfobot) بگیر.
۳. روی سرور خارجی:

```bash
git clone https://github.com/shootingv818/Ipiran.git
cd Ipiran
sudo ./scripts/install-bot.sh \
  --token <BOT_TOKEN> --owner <YOUR_ID> --public-host <FOREIGN_SERVER_IP>
```

نصب‌کننده Xray را (با بررسی checksum) نصب می‌کند، دسترسی سرور به تلگرام را چک
می‌کند، کلیدها را می‌سازد و ربات را به‌عنوان سرویس بالا می‌آورد.

## بعد از نصب، داخل تلگرام

- ربات را باز کن و Start بزن. **فقط اکانت تو** جواب می‌گیرد.
- **افزودن سرور** → لینک vless سرور ایران را بفرست. (از پنل سرور ایران، لینک
  همان کاربر relay را کپی کن.)
- **کاربر جدید** → نام بده، لینک و کانفیگ را بگیر و در v2rayNG یا Hiddify وارد کن.

## سرور ایران از کجا؟

سرورهای ایران را با همان نصب‌کننده‌ی اصلی این مخزن بساز
(`scripts/install.sh`). روی هر سرور ایران یک کاربر بساز (مثلاً به اسم
`relay`)، لینکش را کپی کن و در ربات، «افزودن سرور»، paste کن.

## امنیت

- فقط آی‌دی مالک جواب می‌گیرد؛ بقیه نادیده گرفته می‌شوند.
- سرور خارجی را با کریپتو و بدون هویت بخر تا مالکیتش ناشناس بماند.
- ربات روی سرور خارجی با کاربر غیرروت اجرا می‌شود و فقط یک اجازه‌ی sudo دارد:
  ری‌استارت Xray.
- **هشدار صادقانه:** پیام‌های ربات از سرور تلگرام عبور می‌کنند (چت با ربات
  سر‌به‌سر رمز نیست). برای راحتی عالی است، برای پنهان‌کاری یک ناظر اضافه است.
- این طرح آی‌پی تو را از مقصد و از سرور ایران مخفی می‌کند، ولی اتصال سیم‌کارت
  تو به سرور خارجی در لاگ اپراتور هست؛ در برابر حکومت پنهان‌کاری کامل نیست.

## مدیریت از خط فرمان (اختیاری)

```bash
ipsazctl show
ipsazctl add-server 'vless://...'
ipsazctl list-servers
ipsazctl render --stdout      # دیدن کانفیگ تولیدی Xray
```

بدون هیچ وابستگی از PyPI؛ فقط `python3` و `xray`.
